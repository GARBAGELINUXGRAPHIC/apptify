# Apptify

面向桌面与移动端的 Vue 3 组件库，采用 Apple 风格设计，统一使用 `<apple-*>` 标签。

[npm](https://www.npmjs.com/package/apptify) · [预览组件](https://garbagelinuxgraphic.github.io/apptify/)

## 快速开始

新项目：
```sh
npm create apptify
```

安装后会自带所有组件说明的样例站。Bundle 包含以下组件之外的内容：
- 自动根据 src/views 生成 routes
- lucide icons
- 全局广播通道 `sendMessage`
- 错误页
- 外观设置页
- 各组件 api 与低代码转换器等

仅使用组件：
```sh
npm i apptify
```

仅在已有项目需要迁移到本组件库时使用。
